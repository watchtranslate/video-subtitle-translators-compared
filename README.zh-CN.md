## 为什么用 WatchTranslate

- **YouTube、X、B站等网站的视频都能翻** — 有字幕直接翻译，没有字幕也能生成双语字幕。
- **翻译质量优于传统机翻／实时翻译** — AI 大模型结合上下文，联系前后对话理解语境。
- **字幕可以导出为 SRT / VTT 文件** — 已生成的原文、译文或双语字幕都能下载，在常用播放器里加载。
- **别人翻译过的，你免费看** — 免费注册后，同视频、同字幕来源和语言的已生成字幕免费复用，额度用完也能看。

### 三种用法

同一个账号和点数，在哪都能用。挑一个适合你设备的。

- **没有字幕的视频，也能双语看** (电脑浏览器 · YouTube / X / Bilibili) — 安装浏览器扩展，在原有播放器里点一下翻译图标，无字幕视频边看边生成双语字幕。
- **手机、电脑里的视频，浏览器就能翻** (免安装 · 电脑和手机) — 打开网页播放器，选择自己的本地视频即可开始，无需安装软件。视频留在设备上，字幕边播边生成。
- **浏览器播不了的，App 来播** (App · Windows / Mac / 安卓) — 翻译电脑里的本地视频，浏览器打不开的格式也能播。
- **手机上看视频，也有双语字幕** (手机 App · 安卓) — 播放手机里的视频文件，或在 App 内置浏览器里打开视频网站，点「翻译」就出字幕。原生播放器解码，能播的格式比网页版多。
